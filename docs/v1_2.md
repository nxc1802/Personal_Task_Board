
```python

```

```python

    source_type,
```

```text
sha256(tenant_id|source_type|stream_id)
```

```text
duplicate checkpoint cleanup
```

# Cách tổ chức Sub-Agent để tránh merge conflict

Mỗi Wave nên có một **Integrator Agent** ngoài các implementation agent.

Ví dụ Wave 2:

```text
Agent 2A
services/intelligence/*
services/processing/pipeline.py

Agent 2B
packages/graph_memory/*
Graph sync worker

Agent 2C
services/application/*
services/mcp/*
scripts runtime DI

Agent 2D
tests/*
```

Sau đó:

```text
Integrator
   ↓
rebase agent branches
   ↓
resolve shared API contracts
   ↓
run entire gate
   ↓
merge Wave
```

Không cho hai Sub-Agent cùng sửa `scripts/ptb_cli.py` hoặc `ApplicationService` trong cùng thời điểm nếu có thể tránh.
