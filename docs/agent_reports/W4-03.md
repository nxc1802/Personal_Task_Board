### Key Remediations:
1. **Case-Insensitive Ticket Anchor Correlation:**
   - In `services/processing/src/ptb_processing/correlation/candidate_matcher.py`, broadened Jira and ticket key matching from `\b[A-Z][A-Z0-9]+-\d+\b` to `\b[A-Za-z][A-Za-z0-9]+-\d+\b` with upper-case normalization. Ensures cross-channel events referencing keys in lowercase or mixed case (e.g. `task rep-159`) match existing tasks.
2. **REST API Truthful Health Reporting:**
   - Verified that `ApplicationService.get_sources_health()` accurately reports status according to the state machine hierarchy:
     - `DISABLED` if explicitly disabled in config.
     - `UNCONFIGURED` / `NOT_INSTALLED` when credentials or Playwright sessions are absent.
     - `NEVER_SYNCED` when authentic credentials exist but no checkpoints have been saved.
     - `DEGRADED` when checkpoint timestamps exceed 7 days.
     - `HEALTHY` when checkpoints are recent.
3. **OpenWebUI Tab & FastMCP RBAC Verification:**
   - Verified that OpenWebUI tool wrappers and FastMCP server tools operate in strict alignment with `ApplicationService` as the single source of truth.
   - `read_only=True` default prevents unauthorized writes across remote clients.
