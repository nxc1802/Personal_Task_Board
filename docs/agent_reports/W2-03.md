## Executive Summary

Task **W2-03** delivers the end-to-end, production-ready ingestion pipeline for **Microsoft Outlook** (Direct Graph API + Web Network Interceptor) and ensures interoperability with **Microsoft Teams** (Layer 1A Web Network Interceptor), fully compliant with the canonical W1-03 Acquisition Contract:
- **Outlook Direct Mail Adapter (`OutlookMailAdapter`):** Complete implementation of `discover()`, `backfill()`, `poll_incremental()`, and `health()`.
- **Mail Threads & Quoting:** Intelligent splitting of newly composed email messages from nested quoted/forwarded historical chains (`<blockquote>`, `-----Original Message-----`, Outlook reply headers), preserving `parent_external_id` and `conversation_or_project_id`.
- **Attachments Metadata (Not Content):** Extraction of attachment metadata (`name`, `size`, `contentType`, `isInline`, `id`) while strictly stripping and discarding heavy base64/binary payloads (`contentBytes`) to prevent Neo4j bloat and memory exhaustion.
- **Folder Selection & Pagination:** Folder-based streams (`Inbox`, `SentItems`, etc.) with `@odata.nextLink` and offset pagination.
- **Delta/Incremental Checkpoints:** Scoped resumption from `IngestionCheckpointRecord` (`last_event_timestamp` / `last_external_id` / `cursor_token`), guaranteeing 0 duplicate replay.
- **Auth Expiry & Resilience:** Automatic detection of authentication expiry (HTTP 401/403) raising non-retryable `AdapterAuthenticationError`, exponential backoff for transient network errors (HTTP 5xx), and rate limiting handling (HTTP 429).
- **Health State Differentiation:** Clear distinction between `NOT_CONFIGURED`, `AUTH_REQUIRED`, `RATE_LIMITED`, and `READY` (reporting `AUTH_REQUIRED` when session cookies or API tokens are missing).
- **Interceptor Enhancements:** Support for edited messages (emitting new content hash / idempotency key), deleted messages (`is_deleted` flag and tombstone tracking), and HTTP 429 throttling state transition.
- **Sanitized Fixtures:** Multi-scenario test fixtures (`tests/fixtures/outlook_messages_fixture.json`) covering urgent tasks, threaded replies, forwarded specs with attachments, newsletters, edits, and deletions.
- **Pending Live Tests:** Graceful marking of live browser session verification as `PENDING` when Microsoft auth cookies are absent, ensuring truthful verification.

### 2.2 Mail Thread & Quoted/Forwarded Text Parsing
Implemented HTML parsing (`_HTMLTextExtractor`) and regex delimiter detection (`clean_email_content`):
- Strips HTML cleanly into formatted plain text, separating `<blockquote>` tags.
- Detects split markers:
  - `-----Original Message-----`
  - `-----Forwarded Message-----`
  - `From: ... Sent: ... To: ... Subject: ...`
  - `On <date>, <author> wrote:`
  - `Vào <date>, <author> đã viết:`
  - Divider lines (`____________`)
- Returns `cleaned_body` (fresh message turn), `quoted_text` (previous thread history), `is_reply` (from subject prefix `Re:`/`TL:`), and `is_forwarded` (from subject prefix `Fwd:`/`FW:`/`Chuyển tiếp:`).
- Links conversation thread: `conversation_or_project_id = conv_id`, `parent_external_id = conv_id` (if different from `item_id`).

### 2.3 Attachment Metadata Safety
Email attachments can range from small text files to multi-megabyte PDFs/binaries. The pipeline:
- Extracts structured metadata:
  ```python
  {
      "id": str,
      "name": str,
      "content_type": str,
      "size": int,  # bytes
      "is_inline": bool,
      "last_modified": str
  }
  ```
- Strips `contentBytes`, `rawBytes`, and base64 strings from `raw_payload`.
- Appends an attachment summary to `normalized_text` (e.g. `[Attachments: spec.pdf (154200 bytes)]`) so downstream NLP/LLM extractors know files exist without memory bloat.

### 2.4 Folder Selection & Pagination
- Default folders: `["Inbox"]`, configurable to `["Inbox", "SentItems", "Archive", ...]`.
- `discover()` queries Graph API `/me/mailFolders` if `http_fetcher` / token is present, falling back to configured folders.
- `backfill()` follows `@odata.nextLink` recursively across pages up to 20 pages (or until exhausted), applying time filters (`$filter=receivedDateTime ge ...`).

### 2.5 Delta / Incremental Sync via Checkpoints
- `poll_incremental()` inspects `IngestionCheckpointRecord`:
  - If `cursor_token` (delta link) is present: queries delta endpoint.
  - If `last_event_timestamp` is present: queries messages with `receivedDateTime ge {last_event_timestamp}`.
  - De-duplicates items matching `last_external_id` and timestamp $\le$ `last_event_timestamp`.
  - Re-fetching unchanged messages produces the deterministic 64-character SHA-256 `idempotency_key`, resulting in 0 duplicate records in the database.

### 2.6 Health States & Session Detection
`health()` returns standardized dictionaries distinguishing:
1. **`NOT_CONFIGURED`:** When `not self.graph_token and not self.mailbox` (or both are missing). `configured = False`, `status = "not_configured"`.
2. **`AUTH_REQUIRED`:** When `mailbox` is configured but neither a valid token nor valid cookies in `storage_state.json` exist (or HTTP 401/403 was received). `configured = False`, `status = "AUTH_REQUIRED"`.
3. **`RATE_LIMITED`:** When HTTP 429 was encountered or active rate-limiting backoff is in effect. `status = "RATE_LIMITED"`.
4. **`READY`:** When valid token or unexpired session cookies exist and live connection ping succeeds. `configured = True`, `status = "READY"`.

### 2.7 Teams & Outlook Interceptor Enhancements
- **Edited Messages:** Detects edit timestamps (`edittime`, updated `version`). Generates a new `content_hash` and `idempotency_key` based on edited text, allowing the ingestion pipeline to capture message updates.
- **Deleted Messages:** Detects deletion indicators (`isDeleted`, `changeType == "deleted"`, `messageType == "Control/Status"`, or `deletetime`). Emits canonical records marked with `is_deleted = True` and normalized text `[Status: Deleted]` / `[Message Deleted]`.
- **Throttling (429):** Detects HTTP 429 status from Microsoft endpoints, logs warnings, and transitions interceptor session state to `DEGRADED`.

## 5. Security & Compatibility Impact

- **Tenant Isolation:** Every `RawEventRecord` emitted by `OutlookMailAdapter`, `OutlookNetworkInterceptor`, and `TeamsNetworkInterceptor` enforces `tenant_id == self.tenant_id`. Any cross-tenant injection is rejected by `validate_record`.
- **Secret & PII Hygiene:** No OAuth tokens, client secrets, or auth cookies are printed to stdout or stored in `normalized_text`.
- **Payload Safety:** Large binary attachment bytes (`contentBytes`, base64) are stripped, preventing denial-of-service or database bloat in Neo4j.
- **Backward Compatibility:** All existing test contracts (`test_adapters.py`, `test_checkpoint_isolation.py`, `test_task_t4_multichannel.py`) pass 100% without regression.
