## 2. Remediated Probe Audit Matrix

| Probe ID | Target Subsystem | Injected Fault | Original Failure Root Cause | Targeted Remediation | Post-Fix Result |
| :--- | :--- | :--- | :--- | :--- | :---: |
| **`probe-01-missing-timestamp`** | `L1.Acquisition` | `event_timestamp=None` | `RawEventRecord` contract strictly required datetime, raising Pydantic `ValidationError`. | Added `@model_validator(mode="before")` on `RawEventRecord` to fallback `None` timestamps to `captured_at` or `now_utc`. | 🟢 **PASS** |
| **`probe-04-oversized-text-payload`** | `L1.Sanitizer` | 1.5MB text block | `AcquisitionPipeline` did not enforce buffer limits on `normalized_text`. | Clamped `normalized_text` length to 65536 bytes (64KB buffer ceiling) in `ingest_event`. | 🟢 **PASS** |
| **`probe-05-invalid-source-type`** | `L1.AdapterRouter` | Unknown source `'custom_legacy_crm'` | `SourceType` enum rejected unregistered source string with `ValidationError`. | Preprocessing validator maps unknown or unregistered source types to `SourceType.CODING_AGENT` fallback; handles typo in stream ID. | 🟢 **PASS** |
| **`probe-06-missing-idempotency-key`** | `L1.AcquisitionPipeline` | `idempotency_key=""` | Empty idempotency key was persisted as empty string instead of recomputed hash. | Auto-recomputes deterministic SHA-256 idempotency key using `compute_idempotency_key` when key is missing or blank. | 🟢 **PASS** |
| **`probe-13-corrupted-unicode-null-bytes`** | `L1.Sanitizer` | `\x00` null byte + `\ud800` surrogate | UTF-8 encode crashed with `UnicodeEncodeError` on orphaned surrogates. | Strips null bytes (`\x00`) and removes lone UTF-16 surrogates (`[\ud800-\udfff]`) via regex in sanitizer. | 🟢 **PASS** |
| **`probe-14-future-timestamp-drift`** | `L1.Sanitizer` | Timestamp year 2099 | Future timestamp drift passed without clamping. | Clamps timestamps beyond `now_utc` to current ingestion timestamp (`now_utc`). | 🟢 **PASS** |
| **`probe-15-deep-link-malformed-scheme`** | `L1.Sanitizer` | `javascript:alert(1)` | Unsafe deep link scheme stored without sanitization. | Enforces `http://` or `https://` prefix check; clears malformed or dangerous schemes to `None`. | 🟢 **PASS** |
| **`probe-24-extremely-long-title-truncation`**| `L2.Extractor` | 2000-char continuous title | `LLMExtractedSchema.title` allowed unbounded string lengths. | Added `@field_validator("title", mode="before")` to `LLMExtractedSchema` truncating titles exceeding 255 chars to `v[:255]`. | 🟢 **PASS** |
