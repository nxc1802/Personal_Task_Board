## 1. Vulnerability Analysis & Code Remediation

### 1.1 P0-1: Wildcard CORS with Credentials
- **File:** `services/application/src/ptb_application/api.py`
- **Lines:** 252–267
- **Root Cause:**
  ```python
  # Previous insecure implementation:
  app.add_middleware(
      CORSMiddleware,
      allow_origins=[...],
      allow_origin_regex=r".*",
      allow_credentials=True,
      allow_methods=["*"],
      allow_headers=["*"],
  )
  ```
  Combining `allow_origin_regex=r".*"` with `allow_credentials=True` allowed any arbitrary website visited by the user in their browser to issue authenticated cross-origin requests to `http://localhost:8000`, reading tasks and injecting state.
- **Remediation:**
  ```python
  allowed_origins = [
      origin.strip()
      for origin in os.getenv(
          "PTB_CORS_ORIGINS",
          "http://127.0.0.1:3000,http://localhost:3000,http://127.0.0.1:8000,http://localhost:8000",
      ).split(",")
      if origin.strip()
  ]
  app.add_middleware(
      CORSMiddleware,
      allow_origins=allowed_origins,
      allow_credentials=True,
      allow_methods=["GET", "POST", "PATCH", "DELETE", "OPTIONS"],
      allow_headers=["Authorization", "Content-Type", "X-PTB-API-KEY", "X-PTB-ADMIN-KEY"],
  )
  ```

### 1.2 P0-2: Zero API Authentication
- **File:** `services/application/src/ptb_application/api.py`
- **Lines:** 78–126, 246–249
- **Root Cause:**
  FastAPI application was instantiated without global dependencies, and no endpoint enforced authentication tokens or headers.
- **Remediation:**
  Added dependency `verify_api_key` injected at `FastAPI(..., dependencies=[Depends(verify_api_key)])`:
  ```python
  def verify_api_key(
      request: Request,
      api_key_header: Optional[str] = Header(None, alias="X-PTB-API-KEY"),
  ) -> Optional[str]:
      # Exempt /health and CORS preflight OPTIONS
      norm_path = request.url.path.rstrip("/")
      if norm_path == "/health" or request.method == "OPTIONS":
          return None

      expected_key = os.getenv("PTB_API_KEY")
      if not expected_key or not expected_key.strip():
          logger.warning(
              "PTB_API_KEY is not configured; running in unauthenticated development mode. "
              "Set PTB_API_KEY in production to secure endpoints."
          )
          return None

      provided_key = api_key_header
      if not provided_key:
          auth_header = request.headers.get("authorization")
          if auth_header and auth_header.lower().startswith("bearer "):
              provided_key = auth_header[7:].strip()

      if not provided_key:
          raise HTTPException(
              status_code=status.HTTP_401_UNAUTHORIZED,
              detail="Missing API key. Please provide 'X-PTB-API-KEY' header.",
              headers={"WWW-Authenticate": "ApiKey"},
          )

      if not secrets.compare_digest(provided_key.strip(), expected_key.strip()):
          raise HTTPException(
              status_code=status.HTTP_401_UNAUTHORIZED,
              detail="Invalid API key.",
              headers={"WWW-Authenticate": "ApiKey"},
          )

      return provided_key
  ```

### 1.5 P0-5: Unauthenticated Destructive Reset Endpoint
- **File:** `services/application/src/ptb_application/api.py`
- **Lines:** 128–141, 1550–1555

  ```python
  def verify_admin_key(
      request: Request,
      admin_key_header: Optional[str] = Header(None, alias="X-PTB-ADMIN-KEY"),
  ) -> Optional[str]:
      expected_admin_key = os.getenv("PTB_ADMIN_KEY")
      if expected_admin_key and expected_admin_key.strip():
          if not admin_key_header or not secrets.compare_digest(admin_key_header.strip(), expected_admin_key.strip()):
              raise HTTPException(
                  status_code=status.HTTP_403_FORBIDDEN,
                  detail="Admin authentication required for destructive operation. Provide valid 'X-PTB-ADMIN-KEY' header.",
              )
          return admin_key_header.strip()
      return None
  ```

## 4. Tenant & User Scoping Strategy (P1-4)

### 4.1 Current State (V1 Single-User Local Deployment)
In current V1 architecture:
- `TENANT_ID` defaults to `"local-user"`.
- Application queries operate on a single Neo4j database instance.
- OpenWebUI connects as a local companion interface.

### 4.2 Multi-Tenant / Scoping Strategy (V2 Roadmap)
For multi-tenant or multi-user enterprise deployments:
1. **User Identity Binding:**
   - Every API request authenticated via `X-PTB-API-KEY` or JWT Bearer is mapped to a `SecurityContext(tenant_id: str, user_id: str, roles: list[str])`.
   - `get_application_service()` / route handlers receive `SecurityContext` as a dependency.
2. **Cypher Query Parameter Scoping:**
   - All `TaskDomainRepository`, `RawEventRepository`, and `GraphitiMemoryClient` Cypher queries must append `WHERE task.tenant_id = $tenant_id AND (task.owner_id = $user_id OR task.tenant_id = $tenant_id)`.
   - Neo4j node labels: `(:Task {tenant_id: $tenant_id, user_id: $user_id})`.
3. **MCP Tool Invocation Isolation:**
   - MCP Server instances receive `tenant_id` from the supervisor and reject cross-tenant read/write tool arguments.
   - Eliminates `actor` parameter impersonation (P1-5).

## 5. Migration Notes for Existing Deployments

1. **Development Environment:**
   - If `PTB_API_KEY` is not set in `.env`, the system defaults to dev mode. All local dev tools, curl scripts, and OpenWebUI instances will continue to connect without disruption, while emitting a warning log.
2. **Production Deployment:**
   - Generate a strong random key:
     ```bash
     openssl rand -hex 32
     ```
   - Set in `.env`:
     ```ini
     PTB_API_KEY=<generated_key>
     PTB_ADMIN_KEY=<generated_admin_key>
     PTB_CORS_ORIGINS=http://127.0.0.1:3000,http://localhost:3000
     ```
   - In frontend clients or OpenWebUI functions, include the header:
     `X-PTB-API-KEY: <generated_key>` (or `Authorization: Bearer <generated_key>`).
3. **Docker Compose:**
   - Deploying via `docker compose -f docker-compose.prod.yml up -d` will now enforce `WEBUI_AUTH=True` and pass `PTB_API_KEY`.
   - First user to open OpenWebUI in production will create the administrator account.
