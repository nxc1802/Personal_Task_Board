## 2. Canonical Unified Source Contract

The unified source contract establishes invariants that all data acquisition adapters must strictly obey.

### 2.1 Core Identity and Multi-Tenant Isolation
- **`tenant_id`:** String identifier defining the boundary of isolation (e.g., `'local-user'`, `'tenant-fpt-internal'`, `'client-acme'`). Every RawEvent and Checkpoint must carry `tenant_id`. Adapters must never emit events for a tenant other than their configured `self.tenant_id`.
- **`source_type`:** Member of `SourceType` enum uniquely identifying the source platform.
- **`stream_id`:** String identifier of the logical partition within the source (e.g., Jira Project Key `'PROJ-A'`, Slack Channel ID `'C01234567'`, Git Branch `'main'`, Outlook Mailbox Folder `'Inbox'`, Agent Session ID).
- **`external_id`:** String identifier of the item assigned by the external provider (e.g., Jira issue ID `'10023'`, Slack message timestamp `'1696000000.000100'`, GitHub issue number `'42'`, Outlook message ID).

### 2.2 Deterministic Hashing & Idempotency Formula
To guarantee zero duplicate tasks and zero duplicate events across crashes, restarts, backfills, and poll replays:

1. **Normalized Content Hash (`content_hash`):**
   $$\text{content\_hash} = \text{SHA-256}(\text{strip}(\text{normalized\_text}))$$
   Represented as a 64-character lowercase hex string.

2. **Deterministic Idempotency Key (`idempotency_key`):**
   $$\text{idempotency\_key} = \text{SHA-256}(\text{tenant\_id} : \text{source\_type} : \text{stream\_id} : \text{external\_id} : \text{content\_hash}[:16])$$
   - Scoped strictly per tenant, source, stream, and external entity.
   - If the external item content changes, `content_hash` changes, producing a new `idempotency_key` and allowing the processing pipeline to ingest the update.
   - If the external item content is unchanged, `idempotency_key` is identical, and Neo4j MERGE or pipeline deduplication rejects duplicate creation.

3. **Deterministic Checkpoint ID (`id`):**
   $$\text{checkpoint\_id} = \text{SHA-256}(\text{tenant\_id} : \text{source\_type} : \text{stream\_id})$$
   Enforces a single canonical checkpoint node per source stream per tenant in Neo4j.

### 2.3 Timestamp Standards
- All timestamps (`event_timestamp`, `captured_at`, `created_at`, `updated_at`, `last_event_timestamp`) **must be UTC**.
- Naive datetime objects are converted to UTC via `ensure_utc(dt)`.
- ISO-8601 strings from external APIs (e.g., with `Z` or `+0700` offsets) must be parsed and converted to `datetime(..., tzinfo=timezone.utc)`.

### 2.4 Version, Update, and Delete Handling (`EventAction`)
External systems experience updates (e.g., Jira issue edited, Slack message updated) and deletions:
- **`EventAction.UPSERT` / `UPDATE`:** When content updates, the new `content_hash` triggers a new `RawEventRecord` with updated timestamp. Downstream L2 correlation links it to the existing `UnifiedTask` via `external_id` and provenance evidence.
- **`EventAction.DELETE` / `ARCHIVE`:** Adapters detecting external item deletion emit a `RawEventRecord` with `raw_payload={"action": "delete"}` and `EventAction.DELETE` metadata, enabling downstream status transitions to `DISMISSED` or `DONE`.

### 2.5 Incremental Cursor & Resume Contract
- The incremental cursor is represented by `IngestionCheckpointRecord`:
  - `last_event_timestamp`: Monotonically increasing high-water mark timestamp.
  - `last_external_id`: Tie-breaker identifier for events occurring in the exact same millisecond.
  - `cursor_token`: Optional pagination token or delta link provided by external APIs (e.g., Microsoft Graph `@odata.deltaLink`, Jira pagination `startAt`, Slack next cursor).

### 2.6 Retry, Resilience, and Rate Limiting
- **Transient Failures:** Network timeouts, socket disconnections, and HTTP 5xx errors must trigger exponential backoff with jitter via `execute_with_retry`. Default: 3 retries, initial delay 1.0s, multiplier 2.0x, max delay 60.0s.
- **Rate Limiting (HTTP 429):** Adapters encountering HTTP 429 must inspect the `Retry-After` header. If the requested wait time is within reasonable bounds (e.g., $\le 60\text{s}$), the adapter pauses asynchronously (`handle_rate_limit`). If excessive, it raises `AdapterRateLimitError(retry_after_seconds=...)`.
- **Authentication Standby:** When credentials (`api_token`, `email`, `cookies`) are absent or empty, the adapter must **not** crash or raise fatal exceptions during initialization or health checks. It enters `NOT_CONFIGURED` / `STANDBY` mode, reporting `configured=False`, `status="not_configured"`.

## 3. Standardized Adapter Interface Contract (`AcquisitionAdapter`)

```python
class AcquisitionAdapter(ABC):
    def __init__(
        self,
        source_type: SourceType,
        tenant_id: str = "local-user",
        retry_policy: Optional[RetryPolicyConfig] = None,
        rate_limit_config: Optional[RateLimitConfig] = None,
    ):
        ...

    @abstractmethod
    async def discover(self) -> List[Dict[str, Any]]:
        """Enumerate available streams, channels, workspaces or project keys."""
        pass

    @abstractmethod
    async def backfill(
        self, stream_id: str, since: Optional[datetime] = None
    ) -> AsyncIterator[RawEventRecord]:
        """Fetch historical data from stream_id since given datetime."""
        pass

    @abstractmethod
    async def poll_incremental(
        self, stream_id: str, checkpoint: Optional[IngestionCheckpointRecord] = None
    ) -> AsyncIterator[RawEventRecord]:
        """Fetch newly generated data since checkpoint/cursor."""
        pass

    @abstractmethod
    async def health(self) -> Dict[str, Any]:
        """Report adapter health status (healthy, not_configured, degraded, etc.)."""
        pass
```

### 3.1 The Persist-First Checkpoint Rule
> [!IMPORTANT]
> **Persist-First Durability Invariant:** A checkpoint must **NEVER** be committed or advanced before the raw event is durably written to the persistent store (Neo4j `RawEventRepository`).
> 
> If event persistence fails (due to DB disconnection, disk full, constraint violation):
> 1. Ingestion of the event is marked failed (`success = False`).
> 2. `latest_event` high-water mark does **not** advance.
> 3. `save_checkpoint` is **skipped**.
> 4. Upon restart or retry, the adapter resumes from the last successfully committed checkpoint, ensuring **zero data loss**.

### 3.2 Error Hierarchy
```
AcquisitionError (Exception)
├── AdapterAuthenticationError      # 401 Unauthorized, 403 Forbidden, expired cookie
├── AdapterRateLimitError           # 429 Too Many Requests (carries retry_after_seconds)
├── AdapterTransientError           # 5xx, socket timeout, ECONNRESET (retryable)
├── AdapterConfigurationError       # Missing required parameters/endpoints
└── AdapterStreamNotFoundError      # Channel/stream/project not found on provider
```

## 4. Checkpoint Persistence and Tenant Isolation Architecture

### 4.1 Composite Identity Schema
Neo4j enforces checkpoint uniqueness via composite constraint:
```cypher
CREATE CONSTRAINT c_checkpoint_identity IF NOT EXISTS
FOR (cp:IngestionCheckpoint)
REQUIRE (cp.tenant_id, cp.source_type, cp.stream_id) IS UNIQUE;
```

### 4.2 Repository Operations in `CheckpointRepository`
1. **`get_checkpoint(source_type, stream_id, tenant_id="default")`:**
   Matches `(cp:IngestionCheckpoint)` with exact `tenant_id`, `source_type`, and `stream_id`.
2. **`save_checkpoint(checkpoint: IngestionCheckpointRecord)`:**
   Executes an atomic Cypher `MERGE` on `(cp:IngestionCheckpoint {tenant_id: $tenant_id, source_type: $source_type, stream_id: $stream_id})`, setting `id`, `last_external_id`, `last_event_timestamp`, `cursor_token`, and `updated_at`.
3. **`list_checkpoints(tenant_id: Optional[str] = None)`:**
   Lists checkpoints with optional tenant scoping (`WHERE cp.tenant_id = $tenant_id`).
4. **`delete_checkpoint(source_type, stream_id, tenant_id="default")`:**
   Atomically removes a specific stream checkpoint for safe reset or tenant purge.

## 5. Adapter Author Guide

This guide defines the standard recipe for authors implementing new acquisition adapters (e.g. for Linear, Notion, GitLab, ClickUp, or custom enterprise sources).

### Step 1: Inherit from `AcquisitionAdapter`

```python
        tenant_id: str = "local-user",

        super().__init__(source_type=SourceType.JIRA, tenant_id=tenant_id)
        self.api_token = api_token
```

### Step 2: Implement `health()`
Return structured health reporting `configured=False` when credentials are absent:
```python

        is_configured = bool(self.api_token)
        return {
            "source_type": self.source_type.value,
            "tenant_id": self.tenant_id,
            "configured": is_configured,
            "status": "healthy" if is_configured else "not_configured",
        }
```

### Step 3: Implement `discover()`
Enumerate streams (projects, workspaces, channels):
```python
    async def discover(self) -> List[Dict[str, Any]]:
        # Fetch from remote API or return configured streams
        return [{"stream_id": "proj-1", "name": "Project 1"}]
```

### Step 4: Implement `backfill()` and `poll_incremental()` using `build_raw_event`
Use the base helper `self.build_raw_event(...)` to guarantee all invariants:
```python
    async def backfill(
        self, stream_id: str, since: Optional[datetime] = None
    ) -> AsyncIterator[RawEventRecord]:
        items = await self._fetch_remote(stream_id, since=since)
        for item in items:
            yield self.build_raw_event(
                external_id=str(item["id"]),
                content=item["text"],
                author_id=str(item["user_id"]),
                stream_id=stream_id,
                event_timestamp=item["created_at"],
                raw_payload=item,
            )

    async def poll_incremental(
        self, stream_id: str, checkpoint: Optional[IngestionCheckpointRecord] = None
    ) -> AsyncIterator[RawEventRecord]:
        since = checkpoint.last_event_timestamp if checkpoint else None
        async for record in self.backfill(stream_id, since=since):
            if checkpoint and checkpoint.last_event_timestamp:
                if record.event_timestamp <= checkpoint.last_event_timestamp:
                    if checkpoint.last_external_id and record.external_id == checkpoint.last_external_id:
                        continue
            yield record
```

### Step 5: Wrap External Network Calls in `execute_with_retry`
```python
    async def _fetch_remote(self, stream_id: str, since: Optional[datetime] = None):
        async def _call():
            # Perform HTTP request
            ...
        return await self.execute_with_retry(_call)
```

## 7. Security and Compatibility Impact

1. **Multi-Tenant Isolation:**
   - Adapters explicitly validate `record.tenant_id == self.tenant_id`, rejecting any record with mismatched tenant identity before it enters the ingestion pipeline.
   - Neo4j Checkpoint queries bind `$tenant_id` at the Cypher query level, preventing any tenant from accessing or corrupting another tenant's high-water mark.
2. **Deterministic Deduplication & DoS Prevention:**
   - Content hashing and idempotency keys ensure external systems repeatedly polled or backfilled produce 0 duplicate records in the database, protecting Neo4j from ballooning storage and processing waste.
3. **Standby Health Safety:**
   - Adapters safely report `NOT_CONFIGURED` without raising unhandled exceptions or printing secret keys / tokens to logs.
4. **Backward Compatibility:**
   - Existing adapters (`JiraAdapter`, `ConfluenceAdapter`, `GitHubAdapter`, `SlackAdapter`, `OutlookMailAdapter`, `GitWatcherAdapter`, `AgentWatchersAdapter`) continue to run without requiring immediate changes.
   - Pydantic models in `l1_acquisition.py` maintain all existing field names and post-init compatibility.
