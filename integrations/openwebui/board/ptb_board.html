Cấu hình API Key (X-PTB-API-KEY)
Khi Personal Task Board API (cổng 8000) được cấu hình PTB_API_KEY, mọi yêu cầu giao tiếp từ giao diện cần đính kèm header X-PTB-API-KEY. Khóa này được lưu an toàn trong trình duyệt (localStorage).
